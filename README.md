# Power Zone Website

Marketing website for **Power Zone**, a diesel generator manufacturer.

Live: <https://powerzone-website.vercel.app>

## Pages

| Route | Purpose |
| --- | --- |
| `/` | Landing page |
| `/products` | Generator catalogue |
| `/applications` | Industries and use cases served |
| `/blog`, `/blog/[slug]` | Articles, statically generated per slug |
| `/contact` | Enquiry form |
| `/privacy-policy` | Privacy policy |

## Stack

Next.js App Router, TypeScript, Tailwind CSS. Deployed on Vercel.

## Getting started

The application lives in `power-zone-web/`, not the repository root.

```bash
cd power-zone-web
npm install
npm run dev        # http://localhost:3000
```
